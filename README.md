# ChatGPT Business Hub 企业认领与认证指南

如果你是企业负责人，或受公司委托管理 ChatGPT 上的企业资料，这份 7 页中文指南可以帮你准备申请。认领时要证明你能管理这家企业，例如用企业邮箱接收验证码。接着按页面提示进入 Persona，核实申请人的身份和授权。

**[打开《企业认领与认证指南》PDF](./ChatGPT%20Business%20Hub%20企业认领与认证指南（地区详版）.pdf)**

## 按你现在遇到的问题找页码

| 你想做什么 | 看哪页 | 可以查到什么 |
| --- | --- | --- |
| 第一次申请，想知道该准备什么 | 第 1–2 页 | 核对企业所在地、业务类型和申请人权限，再整理企业登记资料、官网和联系方式。 |
| 查找并认领自己的企业 | 第 3 页 | 搜索企业名称、核对官网，按页面提供的选项用电话、邮箱、域名或 Shopify 验证管理权限。 |
| 已完成认领，准备做身份认证 | 第 4 页 | 找到 Persona 入口，核对企业登记信息，查看可能需要的证件、授权材料和后续邮件。 |
| 搜不到企业、域名验证失败或审核卡住 | 第 5 页 | 按问题找对应的检查步骤，页面底部附官方帮助入口。 |
| 想查公司所在地 | 第 6–7 页 | 按洲查找 ChatGPT 服务地区，再回到第 2 页核对该业务类型的认领条件。 |
